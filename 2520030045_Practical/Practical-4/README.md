# OS Lab Programs

This folder contains Operating Systems lab programs written in C.

## Programs

1. wait_compare.c
   - Demonstrates `fork()`, `wait()`, and `waitpid()`.

2. zombie.c
   - Creates a zombie process for observation.

3. no_zombie.c
   - Eliminates zombie processes using `wait()`.

## Compile

```bash
gcc filename.c -o output
./output
```
